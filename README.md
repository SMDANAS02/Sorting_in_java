# Sorting Algorithms in Java

This repository contains implementations of the most important sorting algorithms in Java. Each algorithm is written with readability and learning in mind, making this repository suitable for students, interview preparation, and Data Structures & Algorithms (DSA) practice.

## 📚 Algorithms Included

- Bubble Sort
- Selection Sort
- Insertion Sort
- Merge Sort
- Quick Sort

## 📊 Complexity Comparison

| Algorithm | Best | Average | Worst | Space | Stable | In-Place |
|----------|------|---------|-------|-------|--------|----------|
| Bubble Sort | O(n) | O(n²) | O(n²) | O(1) | Yes | Yes |
| Selection Sort | O(n²) | O(n²) | O(n²) | O(1) | No | Yes |
| Insertion Sort | O(n) | O(n²) | O(n²) | O(1) | Yes | Yes |
| Merge Sort | O(n log n) | O(n log n) | O(n log n) | O(n) | Yes | No |
| Quick Sort | O(n log n) | O(n log n) | O(n²) | O(log n) | No | Yes |
